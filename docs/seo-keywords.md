## On-page SEO checklist (coding-runzeculture applies per page)

- [ ] Single `<h1>` containing the page's target keyword
- [ ] `<title>` matches the meta title above (≤ 60 chars)
- [ ] `<meta name="description">` matches the meta description above (≤ 160 chars)
- [ ] `<link rel="canonical">` to the canonical URL from `docs/site-map.md`
- [ ] `<html lang="en">`
- [ ] Open Graph + Twitter card tags: `og:title`, `og:description`, `og:image`, `og:url`, `og:type`
- [ ] Schema.org JSON-LD where applicable: `Organization` (Home), `ContactPage` (Contact), `WebSite` (Home), `BreadcrumbList` (all)
- [ ] Sitemap includes all 7 URLs from `docs/site-map.md`
- [ ] `robots.txt` allows all, references the sitemap, blocks `/app-ads.txt`
- [ ] Alt text on every PNG/SVG; descriptive anchor text on every internal link
- [ ] No login or signup walls block crawlers
